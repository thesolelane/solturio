
# 🛡️ Solturio
### *Blockchain Verification & Authenticity for Creators and Tokens*  
> _A Cooperanth Consulting Project_

## 🚀 Overview
**Solturio** is a blockchain-powered authenticity and verification platform that helps **creators**, **token founders**, and **brands** protect their intellectual property (IP) and identity in the decentralized ecosystem.

It provides **proof of first use**, **on-chain verification badges**, and **tamper-proof overlays** that prove originality of logos, tokens, and project assets.

Solturio builds trust across DeFi and NFT markets by linking each verified asset to a **timestamped registry** and an **official verification URL**, preventing impostor tokens, ticker squatting, and copycat branding.

## 🔐 Key Features
| Feature | Description |
|----------|--------------|
| 🧩 **Immutable Proof of First Use** | Timestamped file hashing for original logos and creative assets. |
| 🛡️ **Gold Check Verification Badge** | Automatic overlay watermark that confirms authenticity and registry entry. |
| 🔗 **Unique Verification URL** | Every verification generates a URL linking to on-chain metadata (cannot be faked). |
| 👤 **Creator Wallet Registry** | Connects verified logos to creator wallets or DAO-managed projects. |
| 🧾 **Metadata NFT (Optional)** | Mintable JSON proof stored on Solana via IPFS or Arweave. |
| ⚙️ **API Integration Ready** | Simple REST API (`/api/verify/upload`) for DEXs, NFT markets, and token explorers. |

## 💻 Quick Start (Replit + GitHub)

### 1. Clone or upload the Solturio Kit
Upload the `solturio-kit.zip` or clone the repo in Replit:
```bash
git clone https://github.com/<your-username>/solturio.git
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the server
```bash
npm start
```

Your API runs at:
```text
http://localhost:3000/api/verify/upload
```

### 4. Upload a logo for verification
Use any HTTP client (Postman, curl, etc.):
```bash
curl -X POST -F "asset=@logo.png" http://localhost:3000/api/verify/upload
```

The response includes:
- ✅ `solturio_id`
- 🔗 `stamped_asset_url`
- 🧾 `public_metadata_url`
- ⏰ `timestamp`
- 🔑 `file_hash`
